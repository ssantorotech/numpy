# NumPy Practice

A collection of Python exercises and practical projects focused on learning NumPy, numerical computing, and the fundamental tools used in Data Science and Machine Learning.

## 🎯 Goals

The goal of this repository is to develop practical skills with NumPy through progressive exercises, starting with basic array manipulation and gradually moving toward more advanced numerical operations.

Topics covered include:

- NumPy arrays and dimensions
- Array indexing and slicing
- Reshaping arrays
- Vectorized operations
- Mathematical and statistical operations
- Data manipulation and preprocessing

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ssantorotech/numpy.git
cd array_fundamentals
```

Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

Install dependencies when they are added to `requirements.txt`:

```bash
pip install -r requirements.txt
```
