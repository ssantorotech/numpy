# NumPy Practice

A collection of practical exercises and mini-projects focused on learning **NumPy**, the fundamental Python library for numerical computing and multidimensional array manipulation.

This repository is part of my personal learning journey in **Python, Data Science and Machine Learning**.

The goal is to develop practical skills through progressive exercises, starting with basic array operations and moving towards numerical data analysis and machine learning preprocessing.

## Learning Objectives

- Understand NumPy arrays and multidimensional structures.
- Create, reshape and manipulate numerical arrays.
- Perform indexing and slicing operations.
- Apply vectorized mathematical operations.
- Understand broadcasting and array dimensions.
- Perform statistical analysis on numerical datasets.
- Filter data and identify anomalies.
- Prepare datasets for Machine Learning applications.

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/numpy-practice.git
cd numpy-practice
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Linux/macOS:

```bash
source .venv/bin/activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```
